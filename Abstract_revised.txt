AutoCarto-Agent: A Neuro-Symbolic Architecture for Autonomous Thematic Cartography with Deterministic Spatial Validation
Name: Abdul Kalam Mustaq
Submission Type: Poster Presentation
Topics: Autonomous GIS, Autonomous Spatial Analysis, Modeling, and Research; Generative AI and Agentic Systems in Geospatial Workflows; Spatial Artificial Intelligence: Theory, Causality, and Uncertainty


Large language models exhibit strong capabilities in semantic reasoning and code generation, yet their deployment in autonomous cartography is critically undermined by spatial hallucinations, statistical naïveté, and the absence of enforced mathematical constraints. We present AutoCarto-Agent, a neuro-symbolic architecture that confines an LLM within a deterministic validation framework, with statistical authority strictly bounded by an algorithmic veto system, to produce statistically verified, publication-quality thematic maps from natural language prompts.

Architecture. The system operates on a strict Propose-Verify-Execute triad across three tiers with zero statistical authority leakage from the stochastic layer to the deterministic layer: the LLM may select cartographic templates and assemble declarative code, but every numerical decision (classification breaks, projection choice, colour encoding, simplification tolerance) is either prescribed or vetoed by the deterministic engine. Tier 1, the Semantic Engine, restricts a frozen LLM checkpoint (temperature = 0) to intent parsing, visual variable selection grounded in Bertin's semiology of graphics, selection of a curated and audited .mplstyle template, and declarative code generation; it reasons exclusively about cartographic concepts and never receives raw data values. Tier 2, the Deterministic Execution Engine (DEE), executes all generated code inside an air-gapped, gVisor-isolated sandbox and enforces six algorithmic validation gates. Deterministic stylesheet injection at render time imposes minimalist, high data-ink-ratio cartographic standards on every output, eliminating the default Matplotlib chart-junk surface that would otherwise undermine the publication-quality claim. Spatial computation is routed through a tiered backend (PySAL for small datasets, PostGIS with GiST indexing at intermediate scales, and Apache Sedona for national analyses), preserving topology through Visvalingam-Whyatt simplification for administrative polygons. Tier 3, the Data Fabric, retrieves datasets via a two-stage hybrid pipeline: a deterministic bounding-box filter on a Qdrant vector store enforces strict spatial envelope constraints before semantic ranking is applied to field-level metadata. Because envelope intersection is necessary but not sufficient for true topological overlap, an exact ST_Intersects refinement on the candidate polygons is performed inside Tier 2 prior to computation, mitigating the failure mode in which dense embeddings silently violate spatial topology.

Deterministic Validation Gates. Gate 1 validates CRS integrity and map-type appropriateness. Gate 2 operates as a diagnostic engine rather than a binary gate: it characterises distribution shape (skewness, zero-inflation fraction, Shapiro-Wilk normality), computes Goodness of Variance Fit for proposed classification breaks, and, upon rejection, issues a mandated prescription with pre-computed break points, reducing the LLM to a code-assembler role rather than a statistical decision-maker. Gate 3a computes global Moran's I with queen contiguity weights; |I| < 0.1 triggers choropleth rejection. Gate 3b, activated exclusively for bivariate proposals, applies bivariate Moran's I against a 199-permutation null distribution and Spearman's rank correlation to reject perceptually ambiguous maps when variables lack meaningful spatial cross-correlation. Gate 4 computes Tissot indicatrix areal distortion and rejects projections exceeding a 20 percent threshold. Gate 5 simulates deuteranopia, protanopia, and tritanopia conditions alongside WCAG contrast ratio verification. Gate 6 enforces map completeness including data citations.

Results. We demonstrate end-to-end generation across choropleth, proportional symbol, and bivariate map types using ACS, CDC PLACES, NLCD, and MTBS open datasets. A representative bivariate map of Atlanta tree-canopy loss against asthma hospitalisation rate on 530 Fulton and DeKalb County census tracts (real TIGER geometry, spatially autoregressive synthetic variables on the queen-contiguity weight matrix) yields bivariate Moran's I_xy = 0.326 (p = 0.005, 199 permutations) and Spearman's ρ = 0.947, satisfying both Gate 3b thresholds and unlocking bivariate encoding. The validation suite rejected 23 percent of initial LLM proposals across the full benchmark; projection distortion and zero-inflated classification failures were the dominant rejection categories. 100 percent of attempted sandbox escapes via reflection or dunder traversal were blocked at the AST sanitisation layer.

Reproducibility. The pipeline is containerised under a pinned conda environment. The LLM is frozen at a documented checkpoint with temperature zero and a fixed random seed. Every execution emits a machine-readable JSON trace of all proposals, rejections, diagnostic outputs, and revisions, distributed as an installable Python package with Docker deployment for air-gapped environments.

AutoCarto-Agent establishes a reference architecture for constrained agentic geospatial systems, demonstrating that LLMs can be productively deployed in autonomous cartography when, and only when, their outputs are subject to deterministic spatial validation at every decision point. The framework directly addresses the symposium's themes of autonomous GIS, spatial AI uncertainty, and reproducible geospatial computing.
