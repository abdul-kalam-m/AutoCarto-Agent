A Neuro-Symbolic Architecture for Autonomous Thematic Cartography with Deterministic Spatial Validation
Submission Type: Poster Presentation
Topics: Autonomous GIS, Autonomous Spatial Analysis, Modeling, and Research; Generative AI and Agentic Systems in Geospatial Workflows; Spatial Artificial Intelligence: Theory, Causality, and Uncertainty

Abstract (498 words)
Large language models (LLMs) demonstrate emergent capabilities in code generation and semantic reasoning, yet their application to autonomous cartography remains critically undermined by spatial hallucinations, statistical naïveté, and the absence of mathematical guardrails. We present AutoCarto-Agent, a neuro-symbolic architecture that constrains an LLM within a deterministic spatial validation framework to produce statistically verified, publication-quality thematic maps from natural language prompts.

Architecture. The system operates on a strict Propose-Verify-Execute triad across three tiers with zero authority leakage. Tier 1, the Semantic Engine, restricts the LLM (GPT-4o, temperature=0) to intent parsing, visual variable selection grounded in Bertin's semiology of graphics, template-appropriate stylesheet selection, and declarative code generation. The LLM never consumes raw data values; it reasons exclusively about cartographic concepts. Tier 2, the Deterministic Execution Engine (DEE), executes all generated code within an air-gapped WebAssembly sandbox and enforces six algorithmic validation gates. Tier 3, the Data Fabric, retrieves geospatial datasets via a hybrid architecture: a strict bounding-box payload filter on a Qdrant vector database guarantees spatial intersection before semantic ranking is applied to textual metadata, eliminating the known anti-pattern where dense embeddings destroy spatial topology.

Deterministic Validation Gates. Six gates mathematically verify every map before rendering. Gate 1 validates coordinate reference system integrity and appropriateness for map type. Gate 2 operates as a diagnostic engine, not a binary gate: it characterizes the variable distribution (skewness, zero-inflation fraction, Shapiro-Wilk normality), computes Goodness of Variance Fit for proposed classification breaks, and—upon rejection—issues a mandated prescriptive remedy with pre-computed break points, forcing the LLM into a code-assembler role rather than a statistical decision-maker. Gate 3a computes global Moran's I with queen contiguity weights to confirm spatial structure; if |I| < 0.1, choropleth representation is rejected. Gate 3b, activated exclusively for bivariate proposals, calculates bivariate Moran's I and Spearman's rank correlation to prevent cognitively overloaded maps when variables lack spatial cross-correlation. Gate 4 computes Tissot indicatrix areal distortion and rejects projections exceeding a 20% threshold. Gate 5 simulates deuteranopia, protanopia, and tritanopia vision alongside WCAG contrast ratio verification. Gate 6 enforces completeness of map elements including data citations.

Scale-Aware Computation. The DEE routes spatial computation through a tiered backend: PySAL for datasets under 10,000 features, PostGIS with GiST-indexed spatial joins for datasets up to one million features, and Apache Sedona for national-scale analyses. The fallback strategy respects the Modifiable Areal Unit Problem: polygonal administrative data undergo topology-preserving Visvalingam-Whyatt simplification; H3 hexagon grids are restricted exclusively to point-level and raster data where administrative boundary semantics are absent.

Metadata Quality Gate. Real-world STAC catalogs frequently exhibit missing variable definitions and ambiguous field names. The Data Fabric scores metadata completeness on a seven-point scale: TRUSTED items proceed normally; AUGMENT items trigger automated data profiling that samples 1,000 rows to infer data types and distributions; items scoring below three are rejected with an explicit insufficiency report, preventing LLM hallucination on undocumented variables.

Results. We demonstrate end-to-end generation across choropleth, proportional symbol, and bivariate map types using open data sources including ACS, CDC PLACES, NLCD, and MTBS fire perimeters. A representative bivariate map of Atlanta tree canopy loss against asthma hospitalizations (243 census tracts) completes in 34 seconds wall-clock time, with 90% of latency attributable to LLM API calls rather than spatial computation. The validation suite rejected 23% of initial LLM proposals, with projection distortion and zero-inflated classification failures being the most common rejection categories.

Reproducibility. The complete pipeline is containerized with a pinned conda-lock environment. The LLM is frozen at a documented model version with temperature zero and fixed random seed. Every execution produces a machine-readable JSON trace logging all proposals, rejections, diagnostic outputs, and revisions. The system is distributed as a single installable Python package with a Docker option for air-gapped deployment.

This work establishes a reference architecture for constrained agentic geospatial systems, demonstrating that LLMs can be productively employed in autonomous cartography when—and only when—their outputs are subject to deterministic spatial validation. The framework directly addresses the symposium's core themes of autonomous GIS, spatial AI uncertainty, and reproducible geospatial computing.
