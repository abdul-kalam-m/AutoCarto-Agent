A Neuro-Symbolic Architecture for Autonomous Thematic Cartography with Deterministic Spatial Validation
Name: Abdul Kalam Mustaq
Submission Type: Poster Presentation
Topics: Autonomous GIS, Autonomous Spatial Analysis, Modeling, and Research; Generative AI and Agentic Systems in Geospatial Workflows; Spatial Artificial Intelligence: Theory, Causality, and Uncertainty


Large language models exhibit strong capabilities in semantic reasoning and code generation, yet their deployment in autonomous cartography is critically undermined by spatial hallucinations, statistical naïveté, and the absence of enforced mathematical constraints. We present AutoCarto-Agent, a neuro-symbolic architecture that constrains an LLM within a deterministic validation framework to produce statistically verified, publication-quality thematic maps from natural language prompts.

Architecture. The system operates on a strict Propose-Verify-Execute triad across three tiers with zero authority leakage between stochastic and deterministic layers. Tier 1, the Semantic Engine, restricts a frozen LLM checkpoint (temperature=0) to intent parsing, visual variable selection grounded in Bertin's semiology of graphics, stylesheet selection, and declarative code generation; it reasons exclusively about cartographic concepts and never receives raw data values. Tier 2, the Deterministic Execution Engine (DEE), executes all generated code inside an air-gapped, gVisor-isolated sandbox and enforces six algorithmic validation gates. Spatial computation is routed through a tiered backend—PySAL for small datasets, PostGIS with GiST indexing at intermediate scales, and Apache Sedona for national analyses—preserving topology through Visvalingam-Whyatt simplification for administrative polygons. Tier 3, the Data Fabric, retrieves datasets via a two-stage hybrid pipeline: a deterministic bounding-box filter on a Qdrant vector store guarantees spatial intersection before semantic ranking is applied to field-level metadata, preventing the failure mode in which dense embeddings silently destroy spatial topology.

Deterministic Validation Gates. Gate 1 validates CRS integrity and map-type appropriateness. Gate 2 operates as a diagnostic engine rather than a binary gate: it characterises distribution shape (skewness, zero-inflation fraction, Shapiro-Wilk normality), computes Goodness of Variance Fit for proposed classification breaks, and—upon rejection—issues a mandated prescription with pre-computed break points, reducing the LLM to a code-assembler role rather than a statistical decision-maker. Gate 3a computes global Moran's I with queen contiguity weights; |I| < 0.1 triggers choropleth rejection. Gate 3b, activated exclusively for bivariate proposals, applies bivariate Moran's I and Spearman's rank correlation to reject perceptually ambiguous maps when variables lack meaningful spatial cross-correlation. Gate 4 computes Tissot indicatrix areal distortion and rejects projections exceeding a 20% threshold. Gate 5 simulates deuteranopia, protanopia, and tritanopia conditions alongside WCAG contrast ratio verification. Gate 6 enforces map completeness including data citations.

Results. We demonstrate end-to-end generation across choropleth, proportional symbol, and bivariate map types using ACS, CDC PLACES, NLCD, and MTBS open datasets. A representative bivariate map of Atlanta tree-canopy loss against asthma hospitalisations (243 census tracts) completes in 34 seconds, with 90% of latency attributable to LLM API calls rather than spatial computation. The validation suite rejected 23% of initial LLM proposals; projection distortion and zero-inflated classification failures were the dominant rejection categories.

Reproducibility. The pipeline is containerised under a pinned conda environment. The LLM is frozen at a documented checkpoint with temperature zero and a fixed random seed. Every execution emits a machine-readable JSON trace of all proposals, rejections, diagnostic outputs, and revisions, distributed as an installable Python package with Docker deployment for air-gapped environments.

AutoCarto-Agent establishes a reference architecture for constrained agentic geospatial systems, demonstrating that LLMs can be productively deployed in autonomous cartography when—and only when—their outputs are subject to deterministic spatial validation at every decision point. The framework directly addresses the symposium's themes of autonomous GIS, spatial AI uncertainty, and reproducible geospatial computing.
