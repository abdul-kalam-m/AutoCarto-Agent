Cross-checked: all 530 GEOIDs match `atlanta_tracts_fulton_dekalb.geojson` exactly (0 missing, 0 extra). 11 tracts carry the Census sentinel `-666666666` (no population to estimate from — e.g. Tract 9800 in each county, mostly Hartsfield-Jackson Airport land); the loader treats this as missing, not zero.

**`acs_total_population_2022.csv`** — same keyed ACS API and same connector as the income snapshot; regenerate with **`python scripts/snapshot_acs.py --variable B01003_001E`** (the script's `SNAPSHOTS` registry maps each variable code to its filename and committed SHA-256, so the run is self-verifying). All 530 GEOIDs present, **no Census sentinels** — population is estimable even for tracts where income is not. 2 tracts report a population of exactly 0 (the same non-residential Tract 9800 in each county, mostly airport land); those are real zeros, not missing values, and they drop out of the default dataset anyway because income and asthma are absent there.

This file backs the derived `population_density` variable, which is **not** a raw column: it is population divided by tract polygon area in km², computed *after* reprojection to EPSG:5070 (equal-area), because area in EPSG:4326 degrees is not a real areal unit. Polygon area includes any water inside the tract, so this is tract area rather than Census `ALAND`; Fulton and DeKalb are inland, so the difference is small, but it is an approximation and is recorded here rather than presented as official land area. Resulting density over the 519 analysed tracts: 25.6 – 26,914.9 people/km², median 1,250, skewness 5.95.
